# Smart Fan Controller 🌀

Questo progetto simula il controllo di una ventola in base alla temperatura. 
Utile come esempio di automazione semplice in Python, con una logica di controllo base (tipo embedded systems).

## Funzionalità

- Lettura simulata della temperatura (random)
- Decisione automatica dello stato della ventola: OFF / LOW / MEDIUM / HIGH
- Loop continuo ogni 2 secondi

## Esecuzione

Assicurati di avere Python 3 installato, poi esegui:

```bash
python main.py
